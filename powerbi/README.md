# Power BI

Coloque aqui o arquivo do dashboard.

- **Para versionar bem:** salve como **Power BI Project (.pbip)** em *Arquivo → Salvar como → Arquivos do projeto do Power BI (\*.pbip)*. Se a opção não aparecer, ative em *Opções → Recursos de visualização*. O .pbip vira arquivos de texto e o Git mostra o que mudou (medidas, páginas).
- **Para a entrega no Classroom:** gere também uma cópia `.pbix`.
- **Fonte de dados:** aponte a consulta `clima_cidades` para `data/clima_latam_ampliado.csv` deste repositório (de preferência com um parâmetro de pasta, para cada integrante ajustar o caminho no próprio computador).
