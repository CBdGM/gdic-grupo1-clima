# GDIC – Grupo 1 – Power BI Clima

Projeto de Business Intelligence da disciplina **Gestão de Dados, Informação e Conhecimento (GDIC)**, CIn-UFPE.

## Dataset: Clima LatAm – v1.0.0
`data/clima_latam.csv`: 29 cidades latino-americanas, 17 países, mensal de 1980-01 a 2025-12 (16.008 linhas).

- **Clima:** Open-Meteo Historical Weather API (reanálise ERA5, ECMWF/Copernicus).
- **El Niño / La Niña:** Oceanic Niño Index (ONI), NOAA CPC.
- Gerado por `scripts/baixar.py`. Histórico em [CHANGELOG](CHANGELOG.md).
